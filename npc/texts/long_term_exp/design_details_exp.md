# 数据电路的基础, 触发器, DFF   以及 setup time & hold time
触发器的原理和结构必须非常熟悉

上升沿触发器: 一个clk_n驱动的D-latch 输出 SR 连一个clk驱动的SR-latch   D -> S R -> Q \Q   0 -> 1 0 -> 0 1    1 -> 0 1 -> 1 0
            latch的结构就是两个与门 连两个或非门, 两个或非们交叉反向
master 是 clk_n 驱动, 所以是低电平采样, 高电平锁存
slave 是 clk 驱动, 是低电平锁存, 高电平采样

上升沿触发本质上是一个 采锁->锁采(低电平->高电平) 的接力形式

现在能够轻松理解setup time & hold time:   [二者都是由FF-master本身组合延迟性质决定]

setup time: [这个在分析长路径的时候考虑]
由于master是低电平采样, 所以D的信号必须在上升沿之前就稳定一段时间, 让master能够稳定. 因为一旦上升沿到来, master就锁存了, 如果D还没有稳定, slave采样到的就是错误的数据
所以setup time主要取决于 master的组合路径延时

hold time: [这个在分析短路径的时候考虑]
由于上升沿来之后, master从采样到锁存, 组合路径有延迟(从与门clk_n口到或非们的两个信号口, 两个信号口都变成0, 那么就认为到锁存状态). 
所以下一个D信号不能在master切到锁存状态之前变化


# CDC (clock domain crossing)
# slew, skew, 跨时钟域信号传递, 同步器
# 跨域采样的重点就是: 保证能采样到   保证能采样到正确时序
slew: 边沿时间       skew: 多信号时钟到达时间差

跨时钟域:A->B
最直观的方法当然是用B的时钟直接采样A的信号
但是如果B的时钟周期更慢, 如果要采样的信号的周期小于一个A周期, 就可能采样不到

1. 延长信号使之长于一个B周期
2. 反馈, 保持A中信号直到B采样到(用B的采样后的信号做反馈)   这个方法负担 PPA

多个信号跨域传递:
如果要采样A中多个信号, 如果多个信号之间有skew, 那么B可能会把本来同步变化的(在同一个A时钟周期变化的)多个信号, 采样的不同的B周期里面去

1. 合并, 把这些信号合并成一个长信号, 这样缩小skew
2. 经典同步器, 在A域加一个en信号, en信号在多个待采样信号稳定输出后1-2个周期拉高, 这个时候再采样 (控制信号同步, 同步器)


常见的大量数据同步方式:
1. 握手
2. FIFO
